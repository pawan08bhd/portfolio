# Pawan Raghuwanshi — Software Engineer Portfolio

Personal portfolio website for **Pawan Raghuwanshi**, a Software Engineer / Full-Stack Developer and B.Tech student at SGSITS, Indore.

Built with a clean, minimalist pitch-black engineering aesthetic, focusing on technical depth, architecture, production deployments, and algorithmic problem solving.

## Tech Stack

- **Core**: React 18, Vite
- **Styling**: Vanilla CSS (Handcrafted pitch-black design system)
- **Icons**: Lucide Icons & custom SVG icons
- **Deployment**: Vercel / Netlify compatible

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/pawan08bhd/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
```
